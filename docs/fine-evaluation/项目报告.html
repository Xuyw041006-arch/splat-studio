从照片到可编辑场景

From photographs to an editable scene

Splat Studio 将照片检查、相机恢复、三维高斯训练、物品语义与场景编辑连接成一个桌面流程。用户先选择从照片重建或导入已有成果；每一步只呈现当前需要做的决定，中文和英文可随时切换。

Splat Studio connects capture checks, camera recovery, Gaussian training, object semantics and scene editing in a desktop workflow. Users start from photographs or import a completed reconstruction. Each step presents the decisions needed at that point, and the interface switches between Chinese and English.

本次功能展示使用 macOS 原生 App 操作、Colab A100 执行训练，并分别保存完整视角和六视角的真实成果。

This demonstration operates the native macOS App and trains on a Colab A100, producing separate full-input and six-view results.

一个完整的新建流程

The complete creation workflow

命名场景 → 导入照片 → 确认照片分析建议 → 选择是否识别物品 → 指定并审核重点区域 → 选择快速、均衡或精细及计算设备 → 检查估时并执行 → 打开成果、编辑和保存。

Name the scene → add photos → confirm the capture recommendation → choose appearance-only or semantic reconstruction → specify and review priority regions → select quality and compute device → review the estimate and run → open, edit and save the result.

导入已有成果时，可直接打开完整场景文件，也可导入 PLY 高斯点云及与其匹配的语义包。系统检查高斯顺序、数量与模型哈希，使语义成员对应正确的高斯。

Existing results can be opened as a complete scene, or imported as a Gaussian PLY with its matching semantic package. Point order, count and model hashes bind semantic membership to the correct Gaussians.

照片检查与相机恢复

Capture checks and camera recovery

照片读入时统一 EXIF 方向并记录原始身份。输入检查结合重复照片、特征匹配、照片之间的连接与可选的已知视角覆盖，给出直接重建或稀疏处理建议。分析得到的是重叠证据；真正的相机位置和朝向在几何阶段求解。

Photo ingestion normalizes EXIF orientation and records source identity. Duplicate checks, feature matches, overlap connectivity and optional known coverage produce a recommendation for standard or sparse reconstruction. This analysis supplies overlap evidence; actual camera positions and orientations are solved in the geometry stage.

对于一般静态场景，用户可以上传自己拍摄的、有足够重叠的照片。完整路径通过 COLMAP 提取匹配特征、恢复相机和点云，再用原始 3DGS 优化位置、形状、不透明度和球谐颜色。

Users can supply their own overlapping photographs of a static scene. The standard path uses COLMAP to match features and recover cameras and points, then original 3DGS optimizes position, shape, opacity and spherical-harmonic appearance.

稀疏输入与按需补全

Sparse input and conditional completion

稀疏分支先进行几何验证，包括视差、重投影误差与相机注册。需要学习型几何时使用固定版本 DUSt3R，生成输入支持的点图与相机估计；补充点在对齐、跨视角一致性和可见范围检查通过后加入。

The sparse branch validates parallax, reprojection error and camera registration. When learned geometry is needed, pinned DUSt3R supplies input-supported point maps and camera estimates. Additional points are accepted after alignment, cross-view consistency and visible-support checks.

可观测点、推断点和来源未知点分别记录。稀疏深度约束根据观测可靠程度加权，推断点采用较低权重。自动补全的范围是照片所支持的可见几何；最终接受的补全点数与相机数量以本次训练记录为准。

Observed, inferred and unknown point provenance is recorded separately. Sparse depth constraints are weighted by observation reliability, with lower weights for inferred points. Completion covers visible geometry supported by the photos; the run evidence records the actual accepted additions and registered cameras.

让重要物品获得训练预算

Give important objects a training budget

用户输入重点物品名称后，系统解析成候选类别，并在训练照片中生成实际像素掩码。用户逐张核对绿色区域，剔除误认和重复区域；触及照片边界的物品会标注提示。确认后的区域身份与照片哈希写入训练任务。

Priority text is resolved into candidate labels and actual pixel masks in training photographs. Users inspect the green overlays, rejecting wrong detections and duplicate regions. Objects touching image borders receive a review notice. Confirmed region identities and image hashes are included in the task.

重点区域采用更高的 RGB 损失权重。精细模式在总计 22,000 步内安排最后 2,400 步重点细化，结合区域梯度约束、针对重点相机的训练以及有上限的局部增密。测试报告分别测量小熊和咖啡杯所在区域的绝对画质；是否实际增加高斯与重点相机访问次数由证据文件记录。

Priority regions receive higher RGB-loss weights. Fine mode reserves the final 2,400 of its 22,000 iterations for detail refinement, combining regional gradient constraints, priority-camera training and bounded local densification. Evaluation measures absolute image quality in bear and coffee-mug regions; evidence records actual added Gaussians and priority-camera visits.

层级语义与跨视角置信度

Hierarchy and confidence across views

本次语义输入来自 Grounding DINO 与 SAM 在训练照片上的预测，以及重点区域的人工审核。几何关联将不同照片中的区域连接为三维区域假设；粗区域、物品与局部部件保留层级关系，父子关联通过几何支持检查。

This run uses Grounding DINO and SAM predictions on training photographs, plus human review of priority regions. Geometry associates regions across photos into 3D region hypotheses. Coarse regions, objects and parts retain a hierarchy, with geometry-support checks on parent–child relations.

RGB 重建完成后固定高斯几何，通过可微渲染优化每个高斯的独立语义概率。目标结合平衡 BCE、Dice、边界不确定性权重、跨视角置信度、层级一致性和高置信先验。缺失检测保持未知，避免直接当作负样本。

After RGB reconstruction, Gaussian geometry is frozen and independent per-Gaussian semantic probabilities are optimized through differentiable rendering. The objective combines balanced BCE, Dice, boundary uncertainty weights, cross-view confidence, hierarchy consistency and a high-confidence prior. Missing detections remain unknown instead of becoming negative labels.

三档模式均执行层级和置信度处理，视角数与基础迭代预算随模式调整；有效视角／类别监督对按覆盖策略访问。系统同时保留原始学习概率和补充祖先关系后的语义，评测使用原始概率。仓库还提供 LaGa 格式的多层区域与描述子导入接口。

Every quality profile executes hierarchy and confidence processing; view counts and base iteration budgets vary by profile. Coverage scheduling visits valid view/class supervision pairs. Both raw learned probabilities and ancestor-completed semantics are retained, and evaluation uses the raw probabilities. The repository also provides an importer for LaGa-format multilevel regions and descriptors.

浏览、寻找和可撤销编辑

Explore, find and edit reversibly

Three.js／WebGL 浏览器支持旋转、平移和缩放，保留源模型中的全部高斯与三阶以内的全部球谐系数。核心区域控件可以隐藏远处杂乱背景，同时区分加载数量与当前显示数量。

The Three.js/WebGL viewer supports rotation, panning and zooming while retaining all source Gaussians and all SH coefficients through degree three. Core-region controls hide distant clutter and distinguish loaded points from currently visible points.

有语义的场景支持按名称查找、聚焦、隔离、隐藏和恢复，以及层级区域选择。场景删除采用可撤销的可见性编辑。文字命令可通过本地规则执行，也提供配置外部 LLM 的入口。

Semantic scenes support name search, focus, isolation, hiding, restoration and hierarchical selection. Scene removal uses reversible visibility editing. Text commands can run through local rules, with an optional external-LLM configuration path.

桌面和 GPU 计算分离

Separate desktop interaction from GPU computation

本地训练需要可用的 NVIDIA CUDA 环境、对应 PyTorch、原始 3DGS 扩展与几何依赖。云端通过带完整性校验的任务包交换：导出任务 ZIP，在配置好的 Colab 或其他 GPU 环境执行 cloud_worker，再将成果导回 App。

Local training requires an NVIDIA CUDA environment, matching PyTorch, the original 3DGS extensions and geometry dependencies. Cloud execution exchanges integrity-checked task packages: export a task ZIP, execute cloud_worker on configured Colab or another GPU environment, then import the result into the App.

完整使用说明给出 macOS 桌面、Windows 桌面、本地 NVIDIA、WSL2、Linux GPU、容器和 Colab 的操作步骤。首轮环境安装、模型下载、训练、区域人工审核与文件传输是不同时间成本；报告对其分别标注。

The complete guide covers macOS and Windows desktops, local NVIDIA, WSL2, Linux GPU servers, containers and Colab. Initial environment setup, model downloads, training, manual region review and file transfer are separate time costs, identified separately in the report.

成果保存与可复核性

Save the result and retain its evidence

App 按用户的场景名称导出 .splat.jsonl，包含高斯、球谐、可用语义与显示状态。流式导出避免一次拼接完整的大型 JSON。云端同时保留原始 PLY、语义概率侧文件和任务清单，便于再次打开与独立评测。

The App exports a scene-named .splat.jsonl containing Gaussians, SH, available semantics and display state. Streaming avoids assembling a complete large JSON object at once. Cloud output also retains the original PLY, semantic-probability sidecars and task manifest for reopening and independent evaluation.

此次采用固定的训练／测试划分、模型哈希和完整高斯评测。PSNR、SSIM 衡量渲染图像质量；mIoU 和边界 IoU 衡量人工标注区域的重叠。重点区域分数代表绝对画质，不单独证明重点训练相对于关闭该功能的因果提升。

This experiment uses a frozen training/test split, model hashes and complete-cloud evaluation. PSNR and SSIM measure rendered image quality; mIoU and boundary IoU measure overlap with human masks. Priority ROI scores report absolute quality and do not independently establish a causal improvement over a matched run with priority training disabled.

六视角任务在常规匹配不足后，自动采用 DUSt3R 可见几何初始化，保留 30,000 个经至少两个视角检查的推断点，并使用 101,116 个深度锚点约束训练。几何准备耗时 32.1 秒；重建任务至语义场景保存耗时 486.8 秒，教师识别、排队与最终云端归档另计。

The six-view task automatically uses DUSt3R visible-geometry initialization after insufficient conventional matching, retaining 30,000 inferred points checked by at least two views and 101,116 depth anchors for training. Geometry preparation takes 32.1 seconds; reconstruction through semantic scene save takes 486.8 seconds, excluding prior teacher inference, queuing and final cloud archiving.

完整场景的 RGB 模型达到 2,162,260 个高斯，超过旧版 200 万显示上限。保留已完成的 22,000 步 PLY、提高加载容量后继续后处理与语义训练；没有重复训练 RGB。该次墙钟时间含恢复和等待，不作为干净的速度基准。

The full RGB result contains 2,162,260 Gaussians, exceeding the former two-million display cap. The completed 22,000-step PLY is preserved while capacity is raised and post-processing and semantics continue; RGB is not retrained. This run’s wall time includes recovery and waiting and is not a clean speed benchmark.
