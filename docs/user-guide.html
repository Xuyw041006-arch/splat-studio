02 · 打开 App，准备照片

打开本目录的 Splat Studio.app。这是 0.4.2 / Apple Silicon Mac版本，已在清理旧开发环境后验证独立启动。Mac 不需要安装 Python、CUDA 或 COLMAP；完整训练可选 Colab 或其他 GPU 服务器。Windows 用户先按第 10 章 B 节启动 Windows 包。

每次只上传一个目录里的照片，不要把三组混在一起。选择文件时，进入对应目录后按 ⌘A（Windows 用 Ctrl+A）全选。支持 JPG、PNG、WEBP；iPhone 的 HEIC 请先导出为 JPG。当前云端任务支持 2–300 张照片，单个任务 ZIP 上限 4 GiB。

可以用自己拍的照片吗？相机角度怎么得到？

可以，不需要手动填写每一张的拍摄角度。上传后先检查数量、重复、清晰度和特征重叠；正式重建再根据匹配估计相机位置与朝向。“照片关联比例”不是拍摄角度，也不代表已经覆盖 360°。

  • 围绕同一个静止场景移动拍摄，让相邻照片有明显共同内容。
  • 多拍不同侧面、稍高和稍低的位置；只站在原地转动镜头不足以恢复可靠深度。
  • 保持光照、焦距与曝光尽量稳定，避免运动模糊、反光、透明物体或大面积无纹理区域成为主体。
  • 不要混入不同房间、不同时间已移动的物品；重复照片不会增加有效视角。
  • 可选“拍摄信息”中的覆盖范围只是你提供的辅助信息。内参 JSON 面向有实际标定数据的用户，首次试验留空；当前不支持直接导入外部相机位姿或畸变参数。

03 · 在 App 中完成设置

  1. 首页 → 从 0 开始重建。输入场景名称，例如 teatime。
  2. 添加照片。导入“Teatime-完整-177张”中的全部照片，等待自动进入照片检查。
  3. 核对检查结果 → 确认方案。完整集应推荐直接重建；本版检查过完整集及打乱顺序的输入。几张照片未关联并不等于全部失败，正式相机恢复仍需验证。首次完整集保持“需要时尝试补全”关闭。
  4. 选择“同时识别物品”。如果只需要 RGB 外观，选“仅重建外观”，之后跳过重要物品和确认包流程。
  5. 在“哪些物品需要更清晰？”输入“熊”。第一次只设一个重点，便于确认效果。留空代表不设重点，但开启的普通语义识别仍会执行。
  6. 识别方式保留自动识别。无需填写 API Key。候选词可以留空。多个重点使用逗号分隔，例如“熊、杯子”；每一个重点最终都需要有真实确认区域。
  7. 重建质量选“均衡”。设备选择“云端 GPU” → “Colab” → “NVIDIA A100”。
  8. 勾选“首次使用时下载所需资源”。首次语义识别需要模型；极少视角补全还可能需要几何模型。勾选后将随任务包传递下载许可。“实测速率”未知就留空。
  9. 下一步 → 最后确认。检查场景名、照片数量、重点“熊”、质量“均衡”和设备“A100”。点击“识别并核对区域”，按提示点击 下载物品识别任务。
底部“准备云端重建”暂时灰色是正常的。你填写了重点物品，必须先获得并确认像素区域。仅输入名称不能告诉模型该精细处理哪些高斯。

预计时间是计算范围，包含场景和设置的折算，不是当前 A100 的即时测速；安装、模型下载、上传下载另外计算。此说明的 Colab 配置让 COLMAP 特征阶段使用 CPU，因此这段耗时也可能比 App 的参考值更长。

快速、均衡、精细有什么区别？

所有档位都保留层级语义处理和跨视角置信度；有效监督覆盖可能使语义实际步数超过基础预算。照片数少于预算时按实际可用视角处理。语义步骤在 RGB 之后，不能把表中所有“步数”简单当成同一种耗时单位。精细消耗更多时间和显存，不保证每个物品都比均衡更准。

05 · 回到 App，确认“熊”的区域

  1. 在 App 的“核对重要物品”区域，点击 导入云端重点确认包，选择刚下载的 priority-review.zip。
  2. 打开预览，检查绿色区域是不是你想加强的熊。检查边缘、遮挡，以及是否把杯子、桌子等相邻物品一起选进去了。
  3. 保留正确区域，取消错误区域。对同一只熊，尽量保留多个清楚、互有重叠的视角；无需把每一张都强行选上。
  4. 点击 确认所选区域用于训练。出现已确认区域数量和类别后，关闭预览。
  5. 点击 准备云端重建，下载新的正式重建任务 ZIP。

“确认一个物品”与“只确认一张照片”不同。你可以只把熊作为重点，但多张正确的区域能提供更充分的监督。也不要把两个同名实例不加区分地视为同一件物品。

识别不准或完全没识别出来怎么办？

先确认图片中确实看得见目标。名称使用具体物品，例如“熊”或“teddy bear”，避免“那个重要的东西”。如果自动区域错误较多，可回到重要物品页面，展开“识别与手动标注设置”，点击“手动标注物品 / 部件”。

  1. 选择照片，填写物品名称和跨视角 ID。
  2. 沿物品轮廓连续点击绘制多边形，至少 3 个顶点，然后“保存当前照片掩码”。
  3. 切换照片继续标注；同一实例用相同 ID，不同实例用不同 ID。
  4. 若标注部件，先标注父物品，再填写父 ID 和真实的层级关系。
  5. 重新匹配并确认重点区域，再导出正式任务。

手动方式必须提供像素区域，单独填写候选名称不能代替标注。改变照片或重要物品后，需要重新核对；不要修改已导出的 ZIP 内部内容。

06 · 正式重建、下载和导入

  1. 回到刚才的 Colab，保持同一运行时。从第 2 步重新运行，这次上传新的“正式重建任务 ZIP”，输出应显示“正式重建”，不是“物品识别”。
  2. 按顺序继续运行第 3–7 步。已经安装好的依赖会复用；本次工作目录会重新创建，确认包中的区域随任务携带。
  3. 第 6 步依次进行相机恢复、高斯重建、重要物品细化、层级语义处理与结果保存。原始训练迭代结束后，语义和导出仍可能在执行。
  4. 看到最终状态 completed，再运行第 7 步，下载 scene.splat.jsonl。文件较大时，可以到 Google Drive 的本次任务目录下载。
  5. 回 App 点击“导入重建结果”；或从首页选择“导入已有重建” → 包含物品语义，选择该 JSONL 文件。
  6. 等待完整载入，检查右侧物品列表。选中熊，点击“定位”，开始交互。
App 一直显示“等待云端执行”并不代表 Colab 没在训练。当前没有云端实时进度回传。请在 Colab 第 6 步查看阶段输出，最终以 worker-status.json 的状态和实际产物为准。

是否支持中断后从原来的步数继续？

当前 App 云端 worker 不支持自动断点续训。已有工作目录会被拒绝复用。正常完成后可直接下载；失败重试请重新上传同一个任务包，让笔记本创建新目录。底层训练文件若仍保留，可供进一步诊断，但这份操作流程不会承诺自动恢复此前步数。

完整载入与当前可见数量是两回事。核心范围、隐藏状态和视锥会影响当前可见高斯；App 保留来源模型的全部高斯及原有球谐系数。若输入本来只有 SH1，不会凭空生成 SH3。关闭核心范围后可以查看远处背景，但模糊区域也可能重新出现。

熊的精细处理是在重建时，对确认区域增加训练关注，并在总预算内安排更高分辨率细化和有限增密。导入后的重点标记和“为所选物品配置精细重建”用于准备下一次训练；后者会带入物品名称，仍需提供原照片并重新确认。不会在 Mac 上立即启动远程再训练。前后对比来自相同训练视角，不是独立测试集上的精度保证。

点击右上角 保存成果，选择保存位置，默认文件名取创建场景时的名字，例如 teatime.splat.jsonl。保存当前显示设置之后，再导入会恢复相关可见性设置；原始高斯仍然保留。

稀疏流程根据本次上传的照片恢复相机和几何。补全会引入经过检查的可见区域几何推断，不等于生成了真实的未拍摄背面。两张照片也可能由于纹理、视差或重叠不足而失败。

在高级选项中可以要求“尝试学习式可见区域补全”；保持默认自动通常即可。当前 CUDA 成品流程不支持“外接补全程序”的背面生成路径。对真实物品测量，应补拍缺失面。

09 · 导入已经重建好的模型

  1. 首页选择 导入已有重建。
  2. 选择“仅 RGB 外观”或“包含物品语义”。
  3. 如果有本 App 的 JSONL / JSON 完整场景，只选这个文件即可。不要再附加一个独立语义 ZIP。
  4. 如果使用 PLY，仅 RGB 可以单独导入；包含语义时必须同时选择与这个 PLY 一起生成的 semantics.zip。

语义包和 PLY 会核对模型身份与高斯数量，不同场景、不同训练轮次的文件不能任意组合。priority-review.zip 不是这里要用的语义包。普通摄影测量点云或网格 PLY 也不一定具有 3DGS 所需的完整高斯属性。

D · Windows NVIDIA：在自己的电脑完整训练

Windows App 默认是 CPU 客户端；以下一次性配置完成后，使用启动命令切换到独立 CUDA Python。建议训练环境和源码放在短的英文路径，减少 C++/CUDA 构建路径问题。至少确认 GPU 支持本说明的 CUDA/PyTorch 组合，当前没有针对每一张消费级显卡做过实测。

普通中文操作指令可以本地解析，不要求 LLM。已有兼容服务时，可在启动 App 的终端设置 SPLAT_LLM_BASE_URL、SPLAT_LLM_MODEL、SPLAT_LLM_API_KEY；视觉服务对应 SPLAT_VISION_BASE_URL、SPLAT_VISION_MODEL、SPLAT_VISION_API_KEY。再勾选 App 的对应选项。凭据不会随任务 ZIP 自动传输；云端需要自己设置。这些服务不会代替 CUDA 训练，也不能把仅有名称的物品自动当成已确认像素监督。

脚本命令默认会安装 Python 依赖并按任务需要下载上游代码/模型，但不会替你购买云服务器、安装驱动、执行付费 API 或自动开始训练。prepare / local 负责环境准备；run 才执行任务。当前报告未声称已经完成每一种 GPU 环境的实测。

    with Path(path).open('rb') as f:

def run(args, log=None, cwd=None):
    args = [str(x) for x in args]
    stream = open(log, 'w') if log else None
    proc = subprocess.Popen(args, cwd=cwd, env=os.environ.copy(), stdout=subprocess.PIPE,
                            stderr=subprocess.STDOUT, text=True, bufsize=1, start_new_session=True)
    try:
        for line in proc.stdout:
            print(line, end='', flush=True)
            if stream: stream.write(line); stream.flush()
        if proc.wait(): raise RuntimeError(f'命令失败，日志：{log or "上方输出"}')
    except BaseException:
        # 只停止本单元格启动的进程及其训练子进程。
        if proc.poll() is None:
            os.killpg(proc.pid, signal.SIGTERM)
            try: proc.wait(timeout=10)
            except subprocess.TimeoutExpired:
                os.killpg(proc.pid, signal.SIGKILL); proc.wait()
        raise
    finally:
        if stream: stream.close()

def unpack_task(package, destination):
    """在执行包内代码前检查大小、路径和每个文件的 SHA256。"""
    package, destination = Path(package), Path(destination)
    if destination.exists(): raise ValueError('解压目录必须是新目录。')
    if package.stat().st_size > 4*1024**3: raise ValueError('任务包超过 4 GiB。')
    with zipfile.ZipFile(package) as z:
        infos=z.infolist(); seen=set(); total=0
        if len(infos)>20001: raise ValueError('任务文件过多。')
        for info in infos:
            name=info.filename; parts=name.split('/'); mode=info.external_attr>>16
            if (not name or len(name)>512 or any(c in name for c in ('\\',':','\x00'))
                or PurePosixPath(name).is_absolute() or any(p in ('','.','..') for p in parts)
                or name.casefold() in seen or info.is_dir() or info.flag_bits&1
                or stat.S_IFMT(mode) not in (0,stat.S_IFREG)):
                raise ValueError('不支持的任务 ZIP 路径或文件类型。')
            seen.add(name.casefold()); total+=info.file_size
            if info.file_size>512*1024**2 or total>4*1024**3: raise ValueError('解压内容过大。')
        if 'manifest.json' not in seen: raise ValueError('请选择 App 导出的任务 ZIP，不是确认包、结果包或源码包。')
        if z.getinfo('manifest.json').file_size>8*1024**2: raise ValueError('清单过大。')
        manifest=json.loads(z.read('manifest.json'))
        if manifest.get('format')!='splat-studio-cloud-task/1':
            raise ValueError('请选择 App 导出的任务 ZIP，不是源码 ZIP、确认包或结果包。')
        declared=set()
        for row in manifest['files']:
            name=row['path']
            if name in declared or name=='manifest.json': raise ValueError('任务清单有重复。')
            declared.add(name)
            if z.getinfo(name).file_size!=row['bytes']: raise ValueError('文件长度不匹配。')
            with z.open(name) as f: value=hashlib.file_digest(f,'sha256').hexdigest()
            if value!=row['sha256']: raise ValueError('文件校验失败：'+name)
        if declared|{'manifest.json'}!={i.filename for i in infos}: raise ValueError('任务清单与内容不一致。')
        destination.mkdir()
        for info in infos:
            target=destination/info.filename; target.parent.mkdir(parents=True,exist_ok=True)
            with z.open(info) as src, target.open('xb') as dst: shutil.copyfileobj(src,dst)
    return manifest

Can I use my own photos? Do I need camera angles?

Yes. You do not need to enter a pose for every photo. The initial check examines count, duplicates, sharpness, and feature overlap. Reconstruction later estimates camera position and orientation from matches. Photo connectivity is not angular coverage and does not establish a 360° capture.

  • Move around a static scene and keep substantial overlap between neighboring photos.
  • Capture different sides and heights. Turning the camera without changing position provides weak depth information.
  • Keep lighting and focal length stable. Avoid motion blur and a subject dominated by reflections, transparency, or textureless surfaces.
  • Do not mix unrelated rooms or objects that moved between shots. Duplicate photos do not add views.
  • A known coverage angle is optional guidance. Intrinsics JSON is for calibrated users; leave it blank for the first run. External camera poses and distortion parameters are not imported.

def digest(path):
    with Path(path).open('rb') as f:
        return hashlib.file_digest(f, 'sha256').hexdigest()

def run(args, log=None, cwd=None):
    args = [str(x) for x in args]
    stream = open(log, 'w') if log else None
    proc = subprocess.Popen(args, cwd=cwd, env=os.environ.copy(), stdout=subprocess.PIPE,
                            stderr=subprocess.STDOUT, text=True, bufsize=1, start_new_session=True)
    try:
        for line in proc.stdout:
            print(line, end='', flush=True)
            if stream: stream.write(line); stream.flush()
        if proc.wait(): raise RuntimeError(f'命令失败，日志：{log or "上方输出"}')
    except BaseException:
        # 只停止本单元格启动的进程及其训练子进程。
        if proc.poll() is None:
            os.killpg(proc.pid, signal.SIGTERM)
            try: proc.wait(timeout=10)
            except subprocess.TimeoutExpired:
                os.killpg(proc.pid, signal.SIGKILL); proc.wait()
        raise
    finally:
        if stream: stream.close()

def unpack_task(package, destination):
    """在执行包内代码前检查大小、路径和每个文件的 SHA256。"""
    package, destination = Path(package), Path(destination)
    if destination.exists(): raise ValueError('解压目录必须是新目录。')
    if package.stat().st_size > 4*1024**3: raise ValueError('任务包超过 4 GiB。')
    with zipfile.ZipFile(package) as z:
        infos=z.infolist(); seen=set(); total=0
        if len(infos)>20001: raise ValueError('任务文件过多。')
        for info in infos:
            name=info.filename; parts=name.split('/'); mode=info.external_attr>>16
            if (not name or len(name)>512 or any(c in name for c in ('\\',':','\x00'))
                or PurePosixPath(name).is_absolute() or any(p in ('','.','..') for p in parts)
                or name.casefold() in seen or info.is_dir() or info.flag_bits&1
                or stat.S_IFMT(mode) not in (0,stat.S_IFREG)):
                raise ValueError('不支持的任务 ZIP 路径或文件类型。')
            seen.add(name.casefold()); total+=info.file_size
            if info.file_size>512*1024**2 or total>4*1024**3: raise ValueError('解压内容过大。')
        if 'manifest.json' not in seen: raise ValueError('请选择 App 导出的任务 ZIP，不是确认包、结果包或源码包。')
        if z.getinfo('manifest.json').file_size>8*1024**2: raise ValueError('清单过大。')
        manifest=json.loads(z.read('manifest.json'))
        if manifest.get('format')!='splat-studio-cloud-task/1':
            raise ValueError('请选择 App 导出的任务 ZIP，不是源码 ZIP、确认包或结果包。')
        declared=set()
        for row in manifest['files']:
            name=row['path']
            if name in declared or name=='manifest.json': raise ValueError('任务清单有重复。')
            declared.add(name)
            if z.getinfo(name).file_size!=row['bytes']: raise ValueError('文件长度不匹配。')
            with z.open(name) as f: value=hashlib.file_digest(f,'sha256').hexdigest()
            if value!=row['sha256']: raise ValueError('文件校验失败：'+name)
        if declared|{'manifest.json'}!={i.filename for i in infos}: raise ValueError('任务清单与内容不一致。')
        destination.mkdir()
        for info in infos:
            target=destination/info.filename; target.parent.mkdir(parents=True,exist_ok=True)
            with z.open(info) as src, target.open('xb') as dst: shutil.copyfileobj(src,dst)
    return manifest
