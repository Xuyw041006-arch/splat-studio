The collection contains 24 scenes: 48 original native App captures and 48 captioned 1280 × 720 presentation cards.

The walkthrough covers creation/import, input analysis, appearance-only/semantic choices, priority input and annotation, mask review, quality presets, estimates, local/Colab/server setup, task packaging, the trained Teatime viewer, core filtering, region search/isolation/hiding, text undo and full export.
Six-photo and two-photo branches demonstrate input-triggered sparse/completion recommendations. The six-photo task was packaged; the executed training run uses the full 177-photo Teatime set.

The real Fast A100 run completes 7,000 RGB and 400 semantic iterations, retaining 1,200,686 Gaussians with degree-three spherical harmonics (48 RGB coefficients per Gaussian). Reconstruction through full export takes 45 minutes 50.5 seconds. The report defines timing scope and separately discusses setup, detection, review and transfer.
Fast semantics covers partial regions. The report and isolation captures document this scope; region editing is not presented as complete-object segmentation. All interface images are genuine captures.

Teatime-Fast-A100.zip contains the complete PLY and matching semantic ZIP (~521 MB). It is delivered separately and is not duplicated in the screenshot archive.
