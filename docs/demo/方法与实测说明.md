## 系统如何连接起来 / How the system fits together

桌面端以 Electron 承载双语界面，本地 FastAPI 服务处理照片、场景与任务包，Three.js / WebGL 负责三维浏览。计算任务可以在本机 NVIDIA GPU 或云端 GPU 上运行；Colab 和其他云服务器使用导出任务包、运行脚本、导回成果的流程。实际演示训练在 Colab A100 执行，桌面端在 macOS 操作。

Electron hosts the bilingual desktop interface. A local FastAPI service handles photos, scenes and task packages; Three.js / WebGL renders the viewer. Computation can run on a local NVIDIA GPU or a cloud GPU. Colab and other GPU servers use task export, script execution and result import. This demonstration trains on a Colab A100 and operates the desktop App on macOS.

## 从输入到训练 / From input to training

用户从照片创建场景，也可以导入已有模型。本次照片分析得到 177 张独立照片、97% 连接度，并建议直接重建。连接度用于检查照片间的重叠，不能代替标定结果。相机内外参和稀疏几何由后续 COLMAP 流程求解。本次 COLMAP 特征提取与匹配使用 CPU，3DGS 与语义优化使用 A100 CUDA。

Users can create a scene from photos or import an existing model. This input check found 177 unique photos and 97% connectivity, recommending standard reconstruction. Connectivity checks image overlap; camera calibration still occurs in COLMAP. This run uses CPU COLMAP feature extraction and matching, with A100 CUDA for 3DGS and semantic optimization.

## 物品识别与重点细化 / Object discovery and priority detail

本次输入“熊、咖啡杯”。Grounding DINO 与 SAM 提供图像区域候选，28 个重点候选逐张核对后保留 11 个。白色玩偶被误认为熊、玻璃杯被误认为咖啡杯等候选被取消；边缘处可见的熊身体区域仍保留。名称用于寻找真实像素区域，训练使用经过核对的掩码。

The priority request is “bear, coffee mug.” Grounding DINO and SAM produce image-region candidates. All 28 priority candidates were visually reviewed, retaining 11. Incorrect white-toy and drinking-glass matches were removed; visible bear regions near image boundaries were retained. Names locate candidate objects, while reviewed pixel masks provide training supervision.

重点区域的 RGB 误差获得更高权重。快速模式将最后 400 步用于重点细化：在匹配重点区域的训练相机上提高图像采样分辨率，并对掩码内部的图像梯度增加约束；局部高斯增密受数量预算限制。是否实际新增高斯、访问了哪些相机，由本次任务的证据文件记录。

Reviewed regions receive higher RGB-loss weights. Fast mode reserves its final 400 iterations for priority detail: matching cameras use a denser image grid, with an additional gradient loss inside reviewed regions. Local Gaussian densification has a bounded budget. The run evidence records whether points were actually added and which priority cameras were visited.

## 多视角语义 / Multi-view semantics

本次采用重建后语义嵌入：固定完整 RGB 高斯模型，在多个已标定视角上渲染并优化语义概率。监督包含平衡的 BCE、Dice、边界与不确定性处理，并结合跨视角置信度和层级约束。未检测到物品的视角作为未知监督处理，避免直接当成负样本。

This run attaches semantics after reconstruction. The complete RGB Gaussian model stays fixed while semantic probabilities are rendered and optimized across calibrated views. Supervision combines balanced BCE, Dice, boundary and uncertainty handling, cross-view confidence, and hierarchy constraints. Undetected frame/class pairs remain unknown rather than automatically becoming negatives.

层级包括可见物品集合、物体区域及部件候选。部件关系还要经过显式关系或词汇假设、掩码包含与多视角几何支持检查；最终通过的关系以任务产出为准。实现参考 SAGA / LaGa 的研究思路，不能把这次任务描述成论文完整复现或已证明优于基线。

The hierarchy includes observed object collections, object regions, and part hypotheses. Part relationships require explicit declarations or vocabulary hypotheses, mask containment, and repeated geometric support. Accepted relationships are reported in the run output. The implementation draws on SAGA / LaGa research ideas; this demo is not a complete paper reproduction or evidence of baseline superiority.

本次实际覆盖 12 个语义视角、218 个已观测的“视角—类别”监督对，完成 5 次完整遍历，没有遗漏已观测监督对。输出中的 11 条关系均为集合成员关系 `member_of`；本次未通过物理部件关系，因此展示的层级成果以可见物品集合为范围。跨视角权重结合检测置信度与其他可见视角的一致性，属于工程权重，不是经过标定的正确率。

The actual run covers 12 semantic views and all 218 observed frame/class pairs, completing five sweeps with no observed pair left unvisited. All 11 accepted relationships are `member_of` collection relationships. The demonstrated hierarchy therefore covers observed object collections, without a validated physical-part relationship in this run. Cross-view weights combine detector confidence and agreement in other visible views; they are engineering weights, not calibrated correctness probabilities.

## 产出与评估范围 / Outputs and measurement scope

完整 PLY 保留训练产出的所有高斯及球谐字段；匹配的语义 ZIP 用模型哈希绑定语义概率和物品目录。二者可用于 App 的已有重建导入。高斯点云不等同于网格模型。

The full PLY retains every trained Gaussian and spherical-harmonic field. Its matching semantic ZIP binds probabilities and the object catalog to the model hash. Together they support existing-reconstruction import in the App. A Gaussian point cloud is not a mesh.

本次没有独立的语义真值评测，不报告 mIoU 优势。重点细化的前后指标来自相同训练相机的区域对照，不能作为留出视角评测或“不开重点增强”的消融对比。实测耗时包含几何处理、GPU 优化、完整模型转换和导出，单独列出环境安装与识别时间。

This run has no independent semantic ground-truth evaluation, so it does not establish an mIoU advantage. Priority before/after measurements compare regions in the same training cameras; they are neither held-out evaluation nor an ablation against unweighted training. Actual timing includes geometry, GPU optimization, full-model conversion, and export, with setup and detection reported separately.

本次重点高分辨率训练访问了 7 个相机，共 13 次，局部增密新增点数为 0。原始重点证据中末尾内存快照为 1,207,539 个高斯，而保存并用于语义训练的 PLY 为 1,200,686 个高斯，二者数量不一致。因此图册不将该末尾快照的 PSNR 数字作为最终导出 PLY 的质量指标；这些原始记录保留用于复查。

Priority detail visits seven cameras 13 times, with zero points added by the local densification hook. The original final in-memory priority snapshot records 1,207,539 Gaussians, while the saved PLY used for semantic training contains 1,200,686. Because these counts differ, the showcase does not present that snapshot's PSNR as a quality metric for the exported PLY. The original evidence is retained for inspection.

## 稀疏重建和补全的实现 / Sparse reconstruction and completion

照片读入后统一 EXIF 方向，建立图像身份信息，再检查重复、特征匹配与照片连接度。稀疏分支优先保留通过几何验证的 SfM 初始化，使用三角化、PnP 注册与束调整扩展视角。具备已配置模型资源时，DUSt3R 提供从输入照片预测的可见几何。SfM 不足时可进入学习型初始化；已有有效 SfM 时，只尝试加入经验证的可见区域点。

Photo ingestion normalizes EXIF orientation and records image identity before duplicate, feature-match and connectivity checks. The sparse branch prefers geometrically verified SfM, with triangulation, PnP registration and bundle adjustment. When its configured model resources are available, DUSt3R predicts visible geometry from input photos. It can initialize cases where SfM fails, or propose additional visible points alongside valid SfM geometry.

可见区域补全使用共同观测点估计相似变换，并用留出的对应点检查对齐。新增点还需通过多视角点图一致性、正深度、图像范围和重投影检查；当前实现要求至少两个视角支持，重投影残差小于 3 个特征图像素，并位于 SfM 观测凸包附近。已有 SfM 相机与测量点保持原坐标。预测点标为 inferred，置信度不高于 0.49。

Visible completion fits a similarity transform from shared observations and checks it on held-out correspondences. Candidates must pass point-map consistency, positive-depth, image-bound and reprojection checks. The current implementation requires support in at least two views, reprojection residual below three feature-image pixels, and proximity to the SfM observation hulls. Existing SfM cameras and measurements keep their coordinates. Predicted points are marked inferred with confidence capped at 0.49.

稀疏 CUDA 训练会把有输入像素支持的初始化点投影成逆深度锚点，使用最近点遮挡检查和置信度加权 Smooth L1 约束。该约束是初始化先验；未观测像素不会得到伪造的深度目标。随后用原始 3DGS 的 CUDA 训练器继续优化外观与高斯。

Sparse CUDA training projects input-supported initialization points into inverse-depth anchors, with nearest-point occlusion checks and confidence-weighted Smooth L1 supervision. These anchors are an initialization prior; unobserved pixels receive no fabricated depth target. The original 3DGS CUDA trainer then optimizes appearance and Gaussians.

此次截图新增了六照片稀疏建议、双照片补全建议，并实际导出了一个带人工重点区域的六照片任务包。此次新训练成果为完整 177 张照片的 Teatime；六照片和双照片示例没有在本次截图补拍阶段另行执行 GPU 训练。自动补全的界面含义是按输入支持尝试补充可见几何，不能解释为自动恢复所有不可见背面。

This capture session verifies six-photo sparse and two-photo completion recommendations and exports a six-photo task with a manually reviewed priority region. The newly trained result is the full 177-photo Teatime run. The six- and two-photo examples were not retrained during this screenshot session. Automatic completion means attempting additional input-supported visible geometry, not recovering every unseen backside.
